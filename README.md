# 🎯 R6 Tactical Studio (v0.2.2)

🌍 [简体中文](./README.md) | [English](./docs/README_EN.md) | [日本語](./docs/README_JA.md)

一个免费、好用、轻量化的《彩虹六号：围攻》本地化战术复盘与编辑工作站。

## 1. 为什么需要一个新的彩六战术工具？

直白地讲：**免费的功能不全，功能全的需要付费。**

像 [feml1n/R6TAC_Modify](https://feml1n.github.io/R6TAC_Modify/) 这种老牌开源项目，虽然经典但技术栈陈旧，UI 交互不够现代；而像 [Gamecoach.gg](https://gamecoach.gg/esports/r6siege/) 或 [r6strat.com](https://r6strat.com/featured_strategies) 这类平台，要么核心功能被藏在付费墙后，要么必须全程联网，且功能侧重于展示而非“个人的工作流复盘”。

我在初期思考立项的时候，我认为现在存在的项目存在一个最大的问题，就是**需要全程联网**，登陆的过程实在是繁琐的一笔。那不如直接搞一个本地化的 App，未来再做一个轻量化的 Web 供在线简单编辑，把复杂的内容（视频解析、多图层渲染）留给桌面端。

我希望创建一个真正的工具：**免费、好用、轻量化**。

## 2. 核心设计理念与 All-in-One 工作流

现在的 Web 端都有局限，我也不想复盘时同时开着职业录像播放器和 Web 战术板来回切着编辑。我希望把整个工作流都整合到一个软件里，这样你只需要：

👉 **下载对局视频 ➔ 加载 ➔ 自动分析视频 ➔ 编辑战术板 ➔ 导出分享**

除了工作流的整合，这个项目还有一些我个人的小巧思：
* **用“动画 Layout 表”的思维做推演**：我认为一个动态的过程才是展现战术最好的方法。静态图太死板，所以我引入了时间轴系统，干员怎么走、什么时候交道具，都可以按步骤录入并动态播放。
* **贴合玩家习惯的本地化报点**：官方房间的名称颗粒度不够精细，也不够符合玩家报点的个人习惯。所以我自己手写了房间名，当然也支持自定义标签，完全贴合自己车队的真实交流习惯。

## 3. v0.2.1 核心功能速览

### 🗺️ 多视角多图层画板
* **全景视角**：支持标准、蓝图（Blueprint）、3D视角三种观察视角。
* **精细图层**：垂直防守（C4/穿透位）、楼梯、地图物件均独立分层，配合画笔、路线箭头和抛物线工具，轻松绘制复杂战术。

### ⏱️ 独创的动态时间轴 (Timeline)
* 参考动画设计稿理念，将回合细分为准备、前期、中期和执行阶段。
* 为每位干员分配最多 5 步的跨楼层行动路线，支持一键动画回放，直观推演战术执行流程。

### 📼 视频同步与机器视觉 (OCR) 分析
* **内置播放器**：支持直接将比赛录像拖入软件悬浮播放。
* **AI 视觉切片**：集成机器视觉（OCR）技术，自动读取录像中的回合倒计时和下包状态，精准标记回合关键节点，甚至能直接生成 FFmpeg 脚本帮你一键切分回合视频（电脑中需提前安装）。

### 🤖 AI 战术助手（beta）
* 接入大语言模型，只需输入复盘思路或解说字幕，AI 即可自动提取信息，生成结构化的战术执行表（JSON）和 Markdown 战术简报。

### 📂 纯本地资产库与全格式导出
* **拖拽部署**：侧边栏内置完整的攻防干员与道具库，直接拖拽即可部署。项目文件（`.mty`）纯本地保存。
* **全场景导出**：支持将画板一键导出为高清图片、多阶段战术演示动图（GIF）、PDF 简报以及 Markdown 笔记。

## 5. 技术栈 (Tech Stack)

本项目基于现代化的前端技术栈构建：
* **核心框架**: React 18 + TypeScript
* **状态管理**: Zustand (包含持久化与撤销/重做中间件)
* **Canvas 渲染**: Konva.js / `react-konva`
* **样式与 UI**: Tailwind CSS + Lucide React 图标库
* **机器视觉**: Tesseract.js (用于视频时间戳 OCR 分析)
* **交互拓展**: `react-draggable` (悬浮窗交互), `react-markdown` (AI 简报渲染)

## 6. 快速开始 (Quick Start)

### 环境要求
* Node.js 18+
* pnpm 8+ 或 npm/yarn

### 本地运行
```bash
# 1. 克隆仓库
git clone [https://github.com/yourusername/R6-Tactical-Studio.git](https://github.com/yourusername/R6-Tactical-Studio.git)
cd R6-Tactical-Studio

# 2. 安装依赖
npm install

# 3. 启动开发服务器
npm run dev
```
