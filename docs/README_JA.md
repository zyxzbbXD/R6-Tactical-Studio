# 🛡️ R6 Tactical Studio v0.1.1

🌍 [简体中文](./README.md) | [English](./docs/README_EN.md) | [日本語](./docs/README_JA.md)

> 『レインボーシックス シージ』（Rainbow Six Siege）のために作られた、ミニマルでクロスプラットフォームなタクティカルボード ＆ AI動画レビューツール。オフラインでの携帯性、完全フロントエンドでのハードコアな動画解析、マルチフェーズの動的戦術シミュレーションを主眼に置いています。

---

## 🎯 なぜ新しいR6S用タクティカルツールが必要なのか？

市場にあるレビューツールは肥大化しがちです。約4,000時間をゲームに費やしてきたハードコアプレイヤーとして、本当に使いやすいタクティカルボードに必要なものは何かを熟知しています。それは**「究極の軽量さ」「すぐに使えること」「直感的なレイヤー操作」**です。

既存のツールを調査した結果、明らかな課題が見つかりました：

* **既存ツールの限界:** [feml1n/R6TAC_Modify](https://feml1n.github.io/R6TAC_Modify/)のような古参のオープンソースプロジェクトは、クラシックですが技術スタックが古く、UIや操作性が現代的ではありません。一方、[Gamecoach.gg](https://gamecoach.gg/esports/r6siege/)や[r6strat.com](https://r6strat.com/featured_strategies)のようなプラットフォームは、コア機能が有料だったり、常時オンライン接続が必要だったりし、機能も「個人のワークフロー改善」よりも「プレゼンテーション」に偏っています。
* **現代的なレビューサイクルの欠如:** 従来のボードは静的な線を描くことしかできず、「一人称視点の録画」「マルチフェーズのタイムライン」「戦術平面図」を同じ画面でシームレスに統合することができません。
* **情報処理効率の低さ:** コミュニティで文字ベースの戦術まとめを見たとき、それを頭の中で配置図に変換するのは時間がかかり、労力を伴います。

**💡 私たちのブレイクスルー（コアとなる差別化）:**

1.  **完全ローカルでのハードウェア・アクセラレーション解析:** 独自のローカル動画OCR解析。FFmpegのインストールは不要です。ブラウザのGPUデコーディングとWeb Workerの軽量認識を活用し、試合録画からタイムスタンプ（例：アクションフェーズ開始）を自動的に抽出し、インタラクティブなタイムラインを生成します。
2.  **動的戦術シミュレーション:** 動きのない静的なスクリーンショットとはお別れです。1〜4のフェーズ（準備、序盤、中盤、終盤）にわたる動的な展開をサポートし、ワンクリックでGIF形式の戦術アニメーションを出力できます。
3.  **没入型タクティカル・ブループリント:** 高コントラストのブループリント（青写真）背景と固定のマップ情報パネルを採用し、プロの戦術計画の視点を再現。あなたの戦術共有をより直感的かつ専門的にします。
4.  **究極のポータブル性 (Portable):** Rust/Tauriベースで構築されており、完全にオフラインで動作します。外部環境への依存は一切なく、コピーするだけでどこでも使え、一瞬で起動します。

## ✨ 主な機能 (Features)

* **🗺️ 高度なマップシステム (Advanced Map System)**
    * **マルチビュー切り替え**: 公式の標準見下ろし視点 (Standard)、タクティカル・ブループリント (Blueprint)、3Dアイソメトリック視点 (Isometric) を自由に切り替え可能。
    * **動的オーバーレイ**: 垂直方向の破壊可能エリア (Verticality)、部屋名、階段、ディテール（オブジェクト）などの透明レイヤーを個別に表示切替可能。
    * **カスタムマップインポート**: ローカル画像をドラッグ＆ドロップでアップロードし、階層やビュータイプをカスタマイズ。新しいマップにも数秒で対応。
* **🪖 動的な戦術プランニング (Dynamic Tactical Planning)**
    * **オペレーター＆ガジェットシステム**: サイドバーに全オペレーターと汎用ガジェット（ドローン、C4、有刺鉄線など）を統合。ドラッグ＆ドロップ、拡大縮小、回転をサポート。
    * **4フェーズ・タイムライン**: 1〜4フェーズの戦術シミュレーションをサポート。新しいフェーズに切り替えると、前のフェーズのオペレーター位置が自動的に引き継がれ、微調整するだけで動的なポジショニングを実演できます。
    * **ブループリント・モードの視覚最適化**: ブループリントモードでは、6400x3600の超高解像度ベースを自動レンダリングし、専用の白いワイヤーフレームと左上の固定情報プレートを付属。
* **🎥 内蔵VOD解析 (Built-in VOD Analysis)**
    * **自動タイムスタンプ**: ローカルの `.mp4` 動画をフローティングウィンドウにドラッグすると、カウントダウンUIをワンクリックでスキャン。10秒ごとのサンプリングと数学的な逆算により、進行バー上に「アクションフェーズ」のノードを自動生成します。
    * **没入型レビュー**: グローバルの一時停止、標準、50%、全画面の複数サイズのフローティングウィンドウをサポートし、動画を見ながら描画できます。
* **🤖 AIインテリジェント解析と多言語対応 (AI & i18n)**
    * **多言語とネイティブ用語の適応**: 6ヶ国語（中、英、日、韓、仏、葡）を統合。AIプロンプトとUIは、各言語圏のプレイヤーの慣用句（例：餅つき、デフォルト設置、ハードブリーチなど）に完璧に適合しています。
    * **マルチモーダル一括エクスポート**: 現在のフレームの高画質PNG、Markdown戦術ノート、全フェーズを含むZIP画像集、そして超高速生成される**アニメーションGIF戦術図**のエクスポートをサポート。
    * **モダンな適応型UI**: Light/Darkのスムーズなテーマ切り替え、丸みのあるフォント、レスポンシブなスケーリング設計をサポート。

## 🛠️ 技術スタック (Tech Stack)

* **フロントエンド (UI/UX):** React 18 + Vite + TypeScript + Tailwind CSS
* **デスクトップエンジン:** Tauri (Rust) - 究極に軽量なパッケージングとシステムレベルのウィンドウ管理。
* **キャンバスレンダリング:** React Konva + use-image
* **軽量ローカルOCR:** `tesseract.js` (Web Workerとホワイトリストモードを設定した超高速数値キャプチャ)
* **GIFエンジン:** `gifshot` (KonvaインスタンスをシームレスにキャプチャしてGIFを生成)
* **状態管理:** Zustand

## 🚀 クイックスタート (Getting Started)

PCに `Node.js` (v18+) と `Rust` 環境がインストールされていることを確認してください。

```bash
# 1. リポジトリをクローン
git clone [https://github.com/zyxzbb/r6-tactical-studio.git](https://github.com/zyxzbb/r6-tactical-studio.git)
cd r6-tactical-studio

# 2. 依存関係のインストール
npm install

# 3. 開発サーバーの起動 (Tauri + Vite)
npm run tauri dev
```
