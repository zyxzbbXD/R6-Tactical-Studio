# 🛡️ R6 Tactical Studio v0.1.2

🌍 [简体中文](../README.md) | [English](./README_EN.md) | [日本語](./README_JA.md)

> 『レインボーシックス シージ（Rainbow Six Siege）』専用に開発された、超軽量・クロスプラットフォームの戦術ボード＆AI ビデオ分析ツール。完全オフライン動作、フロントエンドのみでのハードコアな動画解析、多段階のダイナミックな戦術シミュレーションを主眼に置いています。

## 🎯 なぜ新しいR6S戦術ツールが必要なのか？

市販のレビューツールや既存の戦術ボードは機能が肥大化しがちです。約4,000時間をシージに費やしたプレイヤーとして、本当に使いやすい戦術ボードに何が必要かは熟知しています。それは**「究極の軽量さ」「すぐに使えること」「直感的なレイヤー操作」**です。

既存のツールを調査した結果、明らかな課題が見つかりました：

* **既存ツールの限界：** [feml1n/R6TAC_Modify](https://feml1n.github.io/R6TAC_Modify/) のような定番のオープンソースプロジェクトは素晴らしいものの、技術スタックが古く、UIの操作性が現代的ではありません。[Gamecoach.gg](https://gamecoach.gg/esports/r6siege/) や [r6strat.com](https://r6strat.com/featured_strategies) のようなプラットフォームは、コア機能が有料であったり、常時オンライン接続が必要だったりして、「個人のワークフロー」よりも「展示」に重きを置いています。
* **現代的なレビューサイクルの欠如：** 従来の戦術ボードは静的な線を描くことしかできず、「一人称視点（POV）の録画」、「複数フェーズのタイムライン」、「戦術平面図」を1つの画面でシームレスに統合することができませんでした。
* **情報処理の非効率さ：** コミュニティのテキストベースの戦術まとめを読んで、頭の中で立ち回り図に変換するのは非常に労力と時間がかかります。

**💡 私たちのブレイクスルー（核心的な差別化）：**

1.  **完全ローカルでのハードウェア・アクセラレーション解析：** 独自のローカル動画OCR解析とステートマシン防振アルゴリズム。FFmpegのインストールは不要で、ブラウザのGPUデコードとWeb Workerを利用して超高速なフレームスキャンを実現。大会配信（Broadcast）と一人称視点（POV）のUIレイアウトに自動適応し、ラウンドのタイムスタンプを抽出します。
2.  **「容量ゼロ増加」の録画切り抜き：** OSネイティブのFFmpeg無劣化切り抜きスクリプト（`.bat` / `.sh`）をワンクリックで出力する業界初のシステム。ソフトウェア本体の容量を1KBも増やすことなく、数十GBの録画ファイルをミリ秒単位で切り抜くことができます。
3.  **ダイナミックな戦術シミュレーション：** 単一の静的なスクリーンショットとはお別れです。1〜4のフェーズ（準備、序盤、中盤、終盤）にわたる動的な展開をサポート。キーボードでのスムーズなフェーズ切り替えや、ワンクリックでのGIF戦術アニメーション出力が可能です。
4.  **没入感のあるブループリントと自動スケール調整：** 本格的なCADブループリント（青写真）の視点を再現。ピクセルのアルファチャンネルに基づく独自の境界スキャンアルゴリズム（Bounding Box）により、大小さまざまなマップを自動で等倍・中央配置します。
5.  **究極の軽量化 (Portable)：** Rust/Tauriベースで構築されており、外部環境への依存なしに完全オフラインで動作します。コピー＆ペーストだけですぐに使用でき、起動も一瞬です。

## ✨ コア機能 (Features)

* **🗺️ 高度なマップシステム (Advanced Map System)**
    * **マルチビュー切り替え：** 公式のデフォルト俯瞰図 (Standard)、戦術ブループリント (Blueprint)、3Dアイソメトリックビュー (Isometric) を自由に切り替え。アセットのダウングレード保護と空枠防止メカニズムを完備。
    * **ダイナミック・オーバーレイ (Overlays)：** 突き下げ/突き上げ (Verticality)、部屋名 (Room Names)、階段とプロップ (Details) などの透過レイヤーを個別に重ね合わせ可能。
    * **カスタムマップのインポート：** ローカル画像のドラッグ＆ドロップアップロードに対応。階層とビュータイプをカスタム割り当てでき、新マップにも数秒で適応。
* **🪖 動的な戦術シミュレーション (Dynamic Tactical Planning)**
    * **オペレーター＆ガジェットシステム：** サイドバーに全オペレーターと共通ガジェット（ドローン、C4、有刺鉄線など）を統合。ドラッグ＆ドロップ、拡大縮小、回転をサポート。
    * **4フェーズ・タイムライン (Phases)：** 1〜4フェーズの戦術展開をサポート。新しいフェーズに切り替える際、前のフェーズのオペレーターの配置を自動で引き継ぎ、微調整するだけで動的な立ち回りを実演可能。
    * **ブループリントモードの視覚最適化：** ブループリントモードでは、深い青色の6400x3600超高解像度CAD背景を自動レンダリング。専用の白い枠線と左上の固定タイトルブロック（銘板）が、専門的でギークな美しさを演出します。
* **🎥 内蔵ビデオタイムライン解析 (Built-in VOD Analysis)**
    * **超高速の二分探索マーキング：** ローカルの録画ファイルをフローティングプレイヤーにドラッグ＆ドロップするだけ。ワンクリックで二分探索（Binary Search）が作動し、ラウンドの正確な開始・終了時間を特定。プログレスバー上に「準備/アクション/終了」の3色戦術フェーズマーカーを生成します。
    * **没入型レビュー体験：** ダブルクリックでの全画面表示、リサイズ可能なフローティングウィンドウ（標準、50%など）をサポート。キーボードの方向キーを長押しすることで各戦術フェーズ間を瞬時にジャンプし、動画を見ながら描き込みが可能。
* **🤖 AI解析と多言語対応 (AI & i18n)**
    * **多言語とネイティブ用語の適応：** 6ヶ国語（中、英、日、韓、仏、葡）を統合し、各言語圏のプレイヤーの慣用表現（例：ハードブリーチ、デフォルトプラントなど）に完璧に適応。
    * **マルチモーダル出力サイクル：** 現在のフレームの高画質PNG出力、超高速生成のAnimated GIF動画像、およびローカル無劣化ビデオ切り抜きスクリプトの出力をサポート。

## 🛠️ 技術スタック (Tech Stack)

* **フロントエンド (UI & Interaction):** React 18 + Vite + TypeScript + Tailwind CSS
* **デスクトップエンジン:** Tauri (Rust) - 究極の軽量パッケージングとOSレベルのウィンドウ管理を担当。
* **キャンバスレンダリング＆アニメーション:** React Konva + use-image
* **ビデオストリーム＆アルゴリズム:** `tesseract.js` (デュアルモードOCR & ステートマシン二分探索アルゴリズム)
* **GIF生成エンジン:** `gifshot` (Konvaインスタンスのシームレスなキャプチャ)
* **状態管理:** Zustand

## 🚀 クイックスタート (Getting Started)

コンピュータに `Node.js` (v18+) と `Rust` 環境がインストールされていることを確認してください。

```bash
# 1. リポジトリをクローン
git clone [https://github.com/zyxzbb/r6-tactical-studio.git](https://github.com/zyxzbb/r6-tactical-studio.git)
cd r6-tactical-studio

# 2. フロントエンドの依存関係をインストール
npm install

# 3. 開発サーバーを起動 (Tauri + Vite)
npm run tauri dev
```
