# 🎯 R6 Tactical Studio (v0.2.2)

🌍 [简体中文](./README.md) | [English](./docs/README_EN.md) | [日本語](./docs/README_JA.md)

無料で使いやすく、軽量な『レインボーシックス シージ (R6S)』のローカル戦術分析＆編集ワークステーション。

## 1. なぜ新しいR6Sの戦術ツールが必要なのか？

単刀直入に言うと：**無料のものは機能が足りないし、機能が揃っているものは有料だから。**

[feml1n/R6TAC_Modify](https://feml1n.github.io/R6TAC_Modify/) のような老舗のオープンソースプロジェクトはクラシックですが、技術スタックが古くUI/UXがモダンではありません。一方で、[Gamecoach.gg](https://gamecoach.gg/esports/r6siege/) や [r6strat.com](https://r6strat.com/featured_strategies) のようなプラットフォームは、コア機能がペイウォールの向こう側にあったり、常時オンライン接続が必要だったりします。しかも、「個人のワークフローや反省会」よりも「展示・公開」に重点が置かれています。

プロジェクト立ち上げ初期に考えたのは、既存プロジェクトの最大の問題は**常時オンライン接続が必要**なことでした。ログイン手順がとにかく面倒くさい。それならいっそローカルアプリを作ってしまおうと。将来的に軽量なWeb版を作ってオンラインでの簡単な編集に対応するとしても、複雑な処理（動画解析、マルチレイヤーレンダリング）はデスクトップ版に任せるべきだと考えました。

僕が作りたいのは、真のツールです：**無料、使いやすい、そして軽量**。

## 2. コア設計理念と All-in-One ワークフロー

現在のWebツールには限界があります。反省会の時に、プロの試合録画プレイヤーとWebのタクティカルボードを行ったり来たり切り替えて編集するなんてやりたくない。ワークフロー全体を1つのソフトウェアに統合したかったのです。つまり、これだけで完結します：

👉 **試合動画をダウンロード ➔ 読み込み ➔ 動画の自動解析 ➔ タクティカルボードの編集 ➔ エクスポート・共有**

ワークフローの統合以外にも、個人的なちょっとした工夫（こだわり）がいくつかあります：
* **「アニメーションのタイムシート」的な思考でのシミュレーション**: 戦術を表現するには、動的なプロセスを見せるのが一番だと思っています。静止画では硬直的すぎるため、タイムラインシステムを導入しました。オペレーターの移動ルートやガジェットを使うタイミングをステップごとに記録し、動的に再生できます。
* **プレイヤーの習慣に合わせたローカライズされた報告（コールアウト）名称**: 公式の部屋名は粒度が粗く、プレイヤーの実際の報告習慣に合っていないことが多いです。そのため自分で部屋名を手書きしました。もちろんカスタムタグにも対応しているので、自分の固定パーティの実際のコミュニケーションに完全に合わせることができます。

## 3. v0.2.1 コア機能の概要

### 🗺️ マルチビュー・マルチレイヤーキャンバス
* **パノラマビュー**: 標準（Standard）、ブループリント（Blueprint）、3D視点（Isometric）の3つの視点をサポート。
* **高精細レイヤー**: 突き上げ/突き下げ（C4/壁抜きポジ）、階段、マップオブジェクトはすべて独立したレイヤーに分割。ペン、ルート矢印、放物線ツールと組み合わせて、複雑な戦術も簡単に描けます。

### ⏱️ 独自のダイナミックタイムライン (Timeline)
* アニメーションの設計理念を参考に、ラウンドを「準備」「序盤」「中盤」「実行」フェーズに細分化。
* 各オペレーターに最大5ステップの階層をまたぐ移動ルートを割り当て可能。ワンクリックのアニメーション再生に対応し、戦術の実行フローを直感的にシミュレーションできます。

### 📼 動画同期とマシンビジョン (OCR) 解析
* **内蔵プレイヤー**: 試合の録画ファイルを直接ソフトウェアにドラッグ＆ドロップしてフローティング再生が可能。
* **AI ビジュアルスライス**: マシンビジョン (OCR) 技術を統合し、録画内のラウンドのカウントダウンやディフューザーの設置状態を自動的に読み取り、ラウンドの重要なノードを正確にマーク。さらに、FFmpegスクリプトを生成して、ワンクリックでラウンドごとの動画を切り出すことも可能（※PCに事前のFFmpegインストールが必要）。

### 🤖 AI タクティカルアシスタント (Beta)
* 大規模言語モデル (LLM) と連携。反省会のアイデアや実況の字幕を入力するだけで、AIが自動的に情報を抽出し、構造化された戦術実行シート (JSON) とMarkdown形式の戦術ブリーフィングを生成します。

### 📂 完全ローカルのアセットライブラリと全フォーマットへのエクスポート
* **ドラッグ＆ドロップで配置**: サイドバーには攻撃・防衛オペレーターとガジェットの完全なライブラリを内蔵。ドラッグするだけで直接配置できます。プロジェクトファイル（`.mty`）は完全にローカルに保存されます。
* **あらゆるシーン向けのエクスポート**: キャンバスをワンクリックで高解像度画像、マルチフェーズ戦術デモGIF、PDFブリーフィング、Markdownノートとしてエクスポート可能。

## 5. 技術スタック (Tech Stack)

本プロジェクトはモダンなフロントエンド技術スタックで構築されています：
* **コアフレームワーク**: React 18 + TypeScript
* **状態管理**: Zustand (永続化およびUndo/Redoミドルウェアを含む)
* **Canvas レンダリング**: Konva.js / `react-konva`
* **スタイル & UI**: Tailwind CSS + Lucide React アイコンライブラリ
* **マシンビジョン**: Tesseract.js (動画タイムスタンプのOCR解析用)
* **インタラクション拡張**: `react-draggable` (フローティングUI用), `react-markdown` (AIブリーフィングレンダリング用)

## 6. クイックスタート (Quick Start)

### 必要要件
* Node.js 18+
* pnpm 8+ または npm/yarn

### ローカルでの実行
```bash
# 1. リポジトリをクローン
git clone [https://github.com/yourusername/R6-Tactical-Studio.git](https://github.com/yourusername/R6-Tactical-Studio.git)
cd R6-Tactical-Studio

# 2. 依存関係のインストール
npm install

# 3. 開発サーバーの起動
npm run dev
```
